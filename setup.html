MotifKain — Setup PocketBase

Buat 8 koleksi hierarkis + atur CORS dalam satu langkah

Langkah 1 — Buat Koleksi
Petunjuk: Buka Console DevTools
  1. Buka PocketBase Admin: https://katalog-production-104e.up.railway.app/_/
  2. Login dengan akun admin Anda.
  3. Tekan F12 atau klik kanan → Inspect → pilih tab Console.
  4. Biarkan tab ini terbuka, lalu lanjut ke langkah berikutnya.
Catatan: Anda harus login ke PocketBase Admin sebelum menjalankan script di bawah. Buka tab baru, login ke PocketBase, lalu kembali ke tab DevTools ini.
atau
Cara lain: Buka file ini langsung di browser setelah login PocketBase

Jika Anda lebih suka membuka file secara langsung:

  1. Buka PocketBase Admin UI di tab lain dan login.
  2. Di tab DevTools Console PocketBase, paste kode migration script dari file pocketbase/migrations/motifkain-collections.js.
  3. Tekan Enter — script akan otomatis berjalan.
1
Jalankan Migration Script
Buka DevTools Console di PocketBase Admin (F12), lalu copy-paste isi file pocketbase/migrations/motifkain-collections.js ke console dan tekan Enter.
2
Refresh Halaman Admin
Setelah script selesai, tekan F5 (refresh) di halaman PocketBase Admin. Anda akan melihat 8 koleksi baru di sidebar.
3
Verifikasi
Tekan tombol di bawah untuk mengecek apakah koleksi sudah dibuat.
Langkah 2 — Atur CORS
Wajib! Tanpa CORS, frontend Vercel tidak bisa mengambil data dari PocketBase Railway. Ikuti langkah di bawah.
A
Buka Settings → CORS di PocketBase Admin
Di PocketBase Admin: klik Settings (gear icon) → cari tab CORS.
B
Isi kolom seperti ini:
Allowed Origins
Allowed Methods
Allowed Headers
Exposed Headers
Max Age
C
Save
Klik tombol Save di halaman CORS.
Langkah 3 — Masukkan Data Sampel (Opsional)
Setelah koleksi terbuat, Anda bisa langsung mulai memasukkan data via PocketBase Admin UI. Atau gunakan admin.html yang akan saya buat terpisah.

Setup Selesai!

Koleksi sudah dibuat. Sekarang buka katalog.motifkain.com untuk melihat katalog dengan data contoh.
